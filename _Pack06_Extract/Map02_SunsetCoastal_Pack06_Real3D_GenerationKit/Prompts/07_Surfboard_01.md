# Surfboard_01

**Priority:** 7

**Target output:** GLB/GLTF

**Topology target:** 1k-4k tris

## Generation Prompt

Create a single stylized weathered surfboard prop for a tropical sunset mobile game. Slightly worn paint, subtle coastal pattern without text or logos, rounded board shape, small fins, believable thickness, clean PBR textures, lightweight topology, no stand, no background. Optimized for Unity mobile and readable as a decorative prop from elevated cameras.

## Post-generation checks

- Check silhouette from Camera A and Camera B.
- Fix pivot/origin.
- Verify Unity scale.
- Remove unnecessary materials.
- Reduce topology if above target.
- Add simple collider only if required.
- Generate LOD only if justified by size/distance.
