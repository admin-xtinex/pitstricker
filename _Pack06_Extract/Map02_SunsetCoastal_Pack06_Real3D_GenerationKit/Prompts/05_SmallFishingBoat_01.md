# SmallFishingBoat_01

**Priority:** 5

**Target output:** GLB/GLTF

**Topology target:** 12k-30k tris

## Generation Prompt

Create a small weathered tropical coastal fishing skiff for a premium mobile Unity game. Wooden hull, faded paint accents, simple bench seats, coiled rope and one small crate optional, no motor complexity unless very simple, no water, no background, no text. Stylized semi-realistic proportions, readable from elevated cameras, PBR textures, clean topology, optimized for mobile, stable pivot and sensible scale.

## Post-generation checks

- Check silhouette from Camera A and Camera B.
- Fix pivot/origin.
- Verify Unity scale.
- Remove unnecessary materials.
- Reduce topology if above target.
- Add simple collider only if required.
- Generate LOD only if justified by size/distance.
