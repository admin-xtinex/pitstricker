# DockModule_01

**Priority:** 6

**Target output:** GLB/GLTF

**Topology target:** 6k-15k tris

## Generation Prompt

Create a modular tropical dock/jetty section for a stylized mobile Unity game. Weathered wooden planks, simple support posts, slight unevenness, subtle rope attachment points, compact reusable module that can tile end-to-end. No water, no scenery, no text. PBR textures, mobile-friendly topology, clean pivot/origin for modular snapping, good silhouette from elevated three-quarter camera angles.

## Post-generation checks

- Check silhouette from Camera A and Camera B.
- Fix pivot/origin.
- Verify Unity scale.
- Remove unnecessary materials.
- Reduce topology if above target.
- Add simple collider only if required.
- Generate LOD only if justified by size/distance.
