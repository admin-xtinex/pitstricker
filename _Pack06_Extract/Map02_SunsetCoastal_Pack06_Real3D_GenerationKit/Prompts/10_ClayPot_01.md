# ClayPot_01

**Priority:** 10

**Target output:** GLB/GLTF

**Topology target:** 1k-4k tris

## Generation Prompt

Create a weathered terracotta clay pot for a stylized tropical coastal mobile Unity game. Warm terracotta color, subtle surface chips and age, optional very simple wave-like painted motif without text, no plant inside, no environment. PBR textures, lightweight topology, clean base and pivot.

## Post-generation checks

- Check silhouette from Camera A and Camera B.
- Fix pivot/origin.
- Verify Unity scale.
- Remove unnecessary materials.
- Reduce topology if above target.
- Add simple collider only if required.
- Generate LOD only if justified by size/distance.
