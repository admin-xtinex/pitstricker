# HeroPalm_01

**Priority:** 12

**Target output:** GLB/GLTF

**Topology target:** 8k-20k tris

## Generation Prompt

Create one stylized semi-realistic tropical hero palm tree for a premium mobile Unity game. Slightly curved trunk, layered bark detail, healthy green fronds, a few subtle dried fronds, balanced crown silhouette, no coconuts unless minimal, no ground or scenery. Optimized for mobile, PBR textures, fronds suitable for alpha-cutout material if needed, clean pivot at trunk base, designed for elevated sunset-coastal camera views.

## Post-generation checks

- Check silhouette from Camera A and Camera B.
- Fix pivot/origin.
- Verify Unity scale.
- Remove unnecessary materials.
- Reduce topology if above target.
- Add simple collider only if required.
- Generate LOD only if justified by size/distance.
