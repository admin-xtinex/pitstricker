# WoodenPost_Rope_01

**Priority:** 3

**Target output:** GLB/GLTF

**Topology target:** 3k-8k tris

## Generation Prompt

Create a stylized coastal wooden bollard/post with a short thick rope loop/connection suitable for a beach arena boundary. Weathered timber, simple metal or rope fastening, sun-aged surfaces, compact footprint, clean silhouette, no scene background, no text. Designed for repeated placement along a sandy lane in a mobile Unity game. PBR textures, mobile-friendly topology, realistic proportions, clean base/pivot.

## Post-generation checks

- Check silhouette from Camera A and Camera B.
- Fix pivot/origin.
- Verify Unity scale.
- Remove unnecessary materials.
- Reduce topology if above target.
- Add simple collider only if required.
- Generate LOD only if justified by size/distance.
