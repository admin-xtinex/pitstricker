# HeroCoastalRock_01

**Priority:** 1

**Target output:** GLB/GLTF

**Topology target:** 8k-20k tris before LOD

## Generation Prompt

Create a stylized semi-realistic coastal rock cluster for a premium mobile Unity game called Pit Striker, Sunset Coastal map. One cohesive hero rock formation, weathered warm gray-brown stone, subtle algae/moss near the base, rounded erosion, believable natural asymmetry, broad stable base, no floating pieces, no text, no environment, no ground plane. Designed to sit beside a sandy gameplay lane and look good from two elevated three-quarter camera angles. Game-ready proportions, clean silhouette, PBR textures, mobile-conscious topology, watertight where possible.

## Post-generation checks

- Check silhouette from Camera A and Camera B.
- Fix pivot/origin.
- Verify Unity scale.
- Remove unnecessary materials.
- Reduce topology if above target.
- Add simple collider only if required.
- Generate LOD only if justified by size/distance.
