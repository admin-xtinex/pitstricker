# WoodenBarrel_01

**Priority:** 9

**Target output:** GLB/GLTF

**Topology target:** 2k-6k tris

## Generation Prompt

Create a stylized semi-realistic weathered coastal wooden barrel for a mobile Unity game. Darkened metal hoops, sun-aged wood, subtle salt wear, no labels, no text, no scene. PBR textures, efficient topology, clean pivot, suitable as reusable beach dressing.

## Post-generation checks

- Check silhouette from Camera A and Camera B.
- Fix pivot/origin.
- Verify Unity scale.
- Remove unnecessary materials.
- Reduce topology if above target.
- Add simple collider only if required.
- Generate LOD only if justified by size/distance.
