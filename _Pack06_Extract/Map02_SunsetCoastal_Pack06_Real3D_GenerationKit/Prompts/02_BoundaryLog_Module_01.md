# BoundaryLog_Module_01

**Priority:** 2

**Target output:** GLB/GLTF

**Topology target:** 3k-8k tris

## Generation Prompt

Create a modular weathered coastal boundary log for a premium stylized mobile Unity game. One horizontal driftwood/log segment with believable chipped ends, sun-bleached brown wood, subtle rope wear, slightly irregular but straight enough to tile into a gameplay boundary. No sand, no beach scene, no extra props, no text. Clean pivot-friendly geometry, reusable module, PBR materials, mobile-friendly topology, readable from elevated isometric-like cameras.

## Post-generation checks

- Check silhouette from Camera A and Camera B.
- Fix pivot/origin.
- Verify Unity scale.
- Remove unnecessary materials.
- Reduce topology if above target.
- Add simple collider only if required.
- Generate LOD only if justified by size/distance.
