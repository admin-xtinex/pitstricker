# Crate_01

**Priority:** 8

**Target output:** GLB/GLTF

**Topology target:** 1.5k-5k tris

## Generation Prompt

Create a compact weathered wooden fishing crate for a stylized coastal mobile Unity game. Reinforced slats, slightly chipped corners, sun-aged wood, no labels, no text, no contents spilling out. PBR textures, simple reusable geometry, clean pivot, low-poly/mobile-friendly topology.

## Post-generation checks

- Check silhouette from Camera A and Camera B.
- Fix pivot/origin.
- Verify Unity scale.
- Remove unnecessary materials.
- Reduce topology if above target.
- Add simple collider only if required.
- Generate LOD only if justified by size/distance.
