# DriftwoodObstacle_01

**Priority:** 11

**Target output:** GLB/GLTF

**Topology target:** 2k-8k tris

## Generation Prompt

Create a small driftwood obstacle for a marble gameplay arena in a stylized coastal mobile Unity game. One grounded twisted branch/log shape, low profile so it does not obscure gameplay, rounded worn edges, believable beach-weathered wood, no sharp spikes, no environment, no text. PBR textures, mobile-friendly topology, simple collider-friendly silhouette, clean pivot.

## Post-generation checks

- Check silhouette from Camera A and Camera B.
- Fix pivot/origin.
- Verify Unity scale.
- Remove unnecessary materials.
- Reduce topology if above target.
- Add simple collider only if required.
- Generate LOD only if justified by size/distance.
