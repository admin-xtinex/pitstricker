# Pit Striker — Google Play Store Compliance Checklist

*Checklist for publishing Pit Striker to Google Play Console.*

## 1. Technical Compliance
- [ ] Target API Level satisfies current Google Play requirements (Target API 34+).
- [ ] 64-bit compliance verified (ARM64 support active via IL2CPP).
- [ ] App size verified (< 150MB initial download without Play Asset Delivery).
- [ ] App Bundle (`.aab`) format generated.

## 2. Store Assets & Metadata
- [ ] App Icon: 512 x 512 px, 32-bit PNG with alpha.
- [ ] Feature Graphic: 1024 x 500 px, JPG or 24-bit PNG.
- [ ] Minimum 4 Phone Screenshots (16:9 or 18:9 aspect ratio).
- [ ] Short Description (up to 80 characters).
- [ ] Full Description (up to 4000 characters).

## 3. Legal & Privacy
- [ ] Privacy Policy URL hosted and publicly accessible.
- [ ] Content Rating questionnaire completed on Google Play Console.
- [ ] Data Safety Form completed (declaring zero personal data collection or analytics).
